## 1. 已完成的代码能力

以下能力已在 Harmony 端完成实现，行为以 Mobile、Desktop 和现有 Device Link 契约为准：

- 远程任务搜索：按设备并发调用 `local-db:conversations:search`，支持标题/正文命中、筛选、去重、消息定位、防抖、页面代次保护，以及旧端/离线缓存回退。
- 项目顺序同步：支持最近活动/自定义顺序、可见项目拖动、Desktop 正本读写、push 收敛、owner stamp/generation fence、路径归一化和旧端本机回退。
- 消息范围分享：支持独立选择态、逐条勾选、点击消息行、全选/清空/取消、数量和禁用态；分享前冻结投影并复用现有测量、分段、预览和系统分享资源生命周期。
- 运行中生成状态：解析 `outputTokens`、`generationDurationMs`、`generationActive`、`generationReliable`；可靠生成中展示 `tok/s`，不可靠数据只展示累计用量，并在新回合、续跑、完成和断线时清理边界。
- 输入队列：记录远端 projection/message 证据，拒绝本地乐观自证，处理 ACK 丢失、快速出队、刷新代次和重试收敛，正式消息回流会清理全部本地过渡层。
- 错误边界：搜索、项目顺序、历史分页、交互确认、新建任务和队列恢复对 `undefined`、普通错误码及循环引用错误安全降级，不因诊断文本序列化再次抛错。
- Device Link 恢复：设备、任务列表、运行态补快照、队列、交互和消息恢复入口加入
  single-flight，并用连接/恢复代次隔离迟到结果；运行态快照省略项会收敛旧的 running
  投影，且按设备隔离同名任务与 pending interaction。
- 跨设备读隔离：消息历史、流式正文、工作步骤、生成指标、分页状态和本地系统卡入口均
  接受当前 `deviceId` 围栏；同名 `sessionId` 切换电脑时，旧设备投影不会被详情页读取。
- Composer 草稿隔离：已有任务按 `deviceId + sessionId` 保存，避免同名任务在不同电脑间串稿；
  旧版无设备草稿首次被远端设备读取时只认领并迁移一次，新建任务仍使用全局草稿。
- Subagent：持久 `agentTaskStatus` 贯穿解析、历史分页合并、实时渲染和失败/停止终态；工作组支持基于稳定 key 的只读子对话详情，不伪造停止控制。
- Desktop 专属确认：补齐 `rename_sessions_confirm`、`ghost_grant_confirm`，未知类型安全降级为回电脑端处理；`plugin_setup` 的 terminal 状态不显示无效取消操作。

## 4. 尚未执行的设备与 UI 验证

本轮只做了只读设备探测：`devecocli device list` 没有活动设备；本机模拟器均为
HarmonyOS 6.1.1 / API 24，且全部处于停止状态，`devecocli emulator image list --all`
没有可用的 API 26 镜像。没有执行安装、覆盖安装、启动或交互操作，也没有用低于 API 26
的模拟器代替基线验证。

因此以下门禁仍未完成：

- signed HAP 覆盖安装和启动后的真实链路；
- 窄屏、展开横屏、Light、Dark、系统字体放大、减弱动态效果的 UI 回归；
- 搜索历史正文打开、项目跨端拖动、消息选择出图/系统分享面板；
- 队列弱网恢复、Device Link 重连、Subagent 详情返回后的滚动/展开态；
- 新增文案的完整多语言矩阵。当前 Harmony 仍以既有 `zh-CN` 页面文案架构为主，本期新增的
  v1.2.0 文案已查术语表并接入资源文件，但没有伪造 Global 多语言交付。
