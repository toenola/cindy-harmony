# Harmony v1.2.0

> 状态：候选发布（代码开发完成，待设备/UI验收）
>
> 开发分支：`feat/v1.2.0`
>
> 目标平台：HarmonyOS 7.0 / API 26+

## 版本目标

v1.2.0 重点跟进原版 Cindy 最新 Mobile / Desktop 中与远程任务连续性直接相关的能力，
优先补齐远程任务搜索、项目顺序同步、分享范围选择和运行状态展示，并对弱网队列、
Device Link 恢复及 Subagent 历史状态做可靠性收口。

Harmony 的用户可见行为继续以 Mobile 和共享实现为事实源；Desktop 专属管理能力不机械
移植，跨端协议和共享 package 不在本仓自行修改。
