# Harmony v1.2.0 开发计划

> 状态：代码开发完成，候选发布待设备/UI验收
>
> 开发分支：`feat/v1.2.0`
>
> 目标平台：HarmonyOS 7.0 / API 26+

## 1. 交付边界

- 只修改和验证 `apps/harmony`；Desktop、Mobile、共享 package 和服务端不在本版改动范围内。
- 用户可见语义以 Mobile、Desktop 和现有 Device Link 契约为事实源，Harmony 使用 ArkUI 等价实现。
- Desktop 仍是任务、消息、项目顺序和输入队列的权威来源；本地缓存只用于性能和可验证回退。
- 新增 UI 同时使用 Light / Dark 语义 token，并覆盖窄屏、展开横屏、字体放大和减弱动态效果的设计约束。
- 使用本机既有签名配置构建；不提交签名材料，不用卸载或清数据绕过签名问题。

## 2. 已完成的运行时阶段

### 阶段 1：核心用户功能

- [x] 远程权威任务搜索：按设备 fan-out，支持标题/正文、筛选、去重、历史任务打开、旧端和离线回退。
- [x] 项目顺序跨端同步：最近活动/自定义顺序、可见项目拖动、Desktop 正本读写、push 收敛和 owner fence。
- [x] 消息范围分享：独立选择态、逐条勾选、范围冻结、分段预览和系统分享资源复用。
- [x] 运行中生成状态：可靠 `tok/s`、累计 token 降级和 turn/continuation/断线清理。

### 阶段 2：状态真实性与恢复

- [x] 输入队列远端证据、ACK 丢失、快速出队、补拉失败和重试收敛。
- [x] 搜索、历史分页、交互、新建任务和队列错误路径安全处理空值、普通错误码和不可序列化错误。
- [x] Device Link 的设备、任务、消息、队列和交互恢复 single-flight；旧连接结果受代次围栏保护。
- [x] 消息详情读取入口按 `deviceId` 隔离历史、流式、工作步骤、生成指标和分页状态，避免同名任务切换电脑时串投影。
- [x] Composer 草稿按 `deviceId + sessionId` 隔离；兼容旧版无设备键的一次性迁移，新建任务保留全局草稿。
- [x] Subagent 持久终态贯穿解析、历史合并和实时渲染。
- [x] 电脑端专属确认类型的明确只读展示与未知类型安全降级。

### 阶段 3：Subagent 详情

- [x] 工作组进入只读子对话详情，显示父子层级、状态、耗时、正文、工具过程和最终结果。
- [x] 没有共享权威控制能力时不伪造停止按钮；详情使用稳定 key 从最新消息树恢复。
