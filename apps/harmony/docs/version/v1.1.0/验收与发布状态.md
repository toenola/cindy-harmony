## 3. 未执行的验证（发布阻塞）

### 3.1 真实设备 / 模拟器矩阵

**阻塞原因（环境）**：

- 本机 USB 真机状态为 `Offline`（`hdc list targets -v`），未进入 `Connected`；
  按 `项目鸿蒙端开发指南.md` 第 11 节，未经用户明确要求不操作真实设备。
- 可用模拟器均为 **HarmonyOS 6.1.1 (API 24)**：
  Mate X7 / MateBook Pro / MatePad Pro 13 / Pura 90 / Pura X Max，全部 `stopped`。
  本工程 `compatibleSdkVersion` 与 `targetSdkVersion` 均为 `26.0.0`（HarmonyOS 7.0），
  API 24 模拟器无法安装本产物。

因此以下项**未验证**，不得据此宣称完成：

- signed HAP 覆盖安装与启动；
- 窄屏 / 展开横屏 / Light / Dark 目检；
- 断线重连、长会话、快速切换 20 个任务后的内存回落观测；
- **会话分享实际出图与系统分享面板**（截图、编码、面板交互全链路）；
- PhotoViewPicker 受限选择勾选、URI 失效后重新选择；
- 已有能力回归：收起态 Composer、附件入口、队列草稿保护、发送后收起；
- 120Hz 动效连续性与「减弱动态效果」下的可理解性；
- 队列操作触控区 44vp 的实机点按确认。

**解除条件**：提供 API 26 (HarmonyOS 7.0+) 模拟器镜像，或由用户确认可对该真机
操作并使其进入 `Connected`。

### 3.2 安全观测 SDK

Harmony 侧厂商 SDK 未提供，adapter 保持 no-op（见 `平台等价交付记录.md` §3）。
真实接入前需完成隐私、区域、依赖、签名与冷启动评审。

### 3.3 分发渠道

应用市场上架与灰度渠道标识需平台侧材料，不在客户端范围（§1、§2 同文档）。

## 4. 未完成 / 已知限制

- 分享导出已按 builder 同款字体、行高、宽度和内边距测量卡片高度，并读取 API 26
  设备截图上限；仍需真机确认字体回退、系统字号缩放与离屏布局的测量一致性。

  单条超长正文继续拆成多张卡片。
- 分享覆盖层未做真机目检，Light / Dark 仅通过语义 token 成对保证。
