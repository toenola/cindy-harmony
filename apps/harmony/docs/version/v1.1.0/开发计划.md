# Harmony v1.1.0 开发计划

> 状态：开发完成，候选发布受阻于设备环境
>
> 开发分支：`feat/v1.1.0`
>
> 版本范围：除 CAPTCHA 外，完成本轮 Mobile 差异的 Harmony 跟进
>
> 发布目标：可构建、可覆盖安装、可回归的 HarmonyOS 7.0 / API 26+ v1.1.0

## 1. 交付原则

- 只修改和验证 `apps/harmony`；需要共享协议或服务端变化时先列为外部依赖。
- Mobile / 共享代码定义行为语义，Harmony 负责 ArkTS 状态和 ArkUI 原生交互。
- 桌面端始终是任务和消息事实源；本地缓存只服务恢复与性能。
- 所有新增或修改 UI 同时实现 Light / Dark，支持窄屏、展开横屏、字体放大和减弱动态效果。
- 不覆盖本机 `build-profile.json5` 签名配置，不提交签名信息，不用卸载或清数据绕过安装问题。
- 每个阶段以可验证结果收尾，不把核心可靠性集中到发布前补测。

## 2. 阶段与工作项

### 阶段 0：基线、事实源和版本身份

目标：消除实现前的协议 / 版本歧义，建立 v1.1.0 可追踪基线。

- [x] 把 Harmony 旧文档中的 `cindy-protocol` 和
  `docs/dev-rules/protocol-and-submodules.md` 引用更新为当前
  `packages/device-link-protocol` 与 `docs/dev-rules/protocol-compatibility.md`。
- [x] 对照 Mobile / 共享实现固化本版 fixture：计划跨轮、时长、Pi roster、默认模型、
  slash 投影、消息淘汰和 1013 重连。（以各阶段单测形式落地，共 127 项）
- [x] 明确自动化任务的权威分类字段，禁止通过标题猜测 scheduler 类型。
- [x] 明确会话分享所需 Harmony API 26 原生能力和单图像素 / 内存上限。（见技术设计 §6.3：8192px 纹理上限）
- [x] 定义 `versionCode` 递增策略，并在发布阶段同步 v1.1.0 三处版本身份。（见平台等价交付记录 §1）

完成标准：差异评估无未裁决运行时项；所有 P0 行为都有测试入口或真实交互场景。

### 阶段 2：消息生命周期与内存治理

目标：任务切换、长会话和自动化任务运行时不展示旧数据、不无限占用内存、不丢本地工作。

- [x] 为历史读取、实时 push、补拉和订阅回调增加 device / session / generation authority fence。
- [x] 离开、重新聚焦和切换任务时推进代次，拒绝旧异步结果回写。
- [x] 自动化任务仅保留一个可见 80 行窗口，离开后回收隐藏内容，不做长期消息快照。
- [x] 普通任务离开后压缩尾窗，并加入约 64 MiB / 800 行全局预算。
- [x] 建立本地工作租约，保护系统卡、乐观消息、流式消息、草稿、队列、交互和上传。
- [x] 将内存淘汰与持久快照删除彻底分离。
- [x] 保留现有请求 lease、订阅串行、最新 80 行快照与 gap healing 语义。

主要入口：

- `core/messages/MessageStore.ets`
- `core/AppServices.ets`
- `pages/TaskPage.ets`
- `entry/src/test/LocalUnit.test.ets`

完成标准：快速切换 20 个长任务后内存回落；旧 push 不污染当前页；任何淘汰场景都不清空新草稿或未完成操作。

### 阶段 3：Device Link 1013 拥塞恢复

目标：短暂重连成功不清除拥塞历史，避免 1013 高频抖动。

- [x] 将 1013 拥塞 streak / cooldown 重置改为连续成功 15 分钟。
- [x] 连接代次变化时取消旧计时器，显式停止时完整回收。
- [x] 增加重复 1013、短成功、长稳定、非 1013 和计时器竞态测试。
- [ ] 回归前后台、网络切换、鉴权失败、撤权和消息补拉。（需真机 / 模拟器，见阶段 7）

主要入口：

- `core/device-link/DlClient.ets`
- `core/AppServices.ets`
- `entry/src/test/LocalUnit.test.ets`

完成标准：15 分钟内重复 1013 按同一拥塞期累计；稳定窗结束后才恢复初始策略；不改变 wire capability。

## 3. 依赖与推荐顺序

```text
阶段 0 基线与事实源
  ├─> 阶段 1 消息 / Pi / 模型正确性
  ├─> 阶段 2 消息生命周期
  └─> 阶段 3 Device Link

阶段 1 ─> 阶段 4 Composer 与标题
阶段 0 + 阶段 2 ─> 阶段 5 会话分享
阶段 0 ─> 阶段 6 平台等价交付

阶段 1～6 全部完成 ─> 阶段 7 发布收口
```

并行建议：阶段 2、阶段 3 可分别开发；阶段 5 的系统 API 验证可与阶段 1 并行，但最终
合入前必须使用阶段 2 的资源和 authority 生命周期。阶段 6 中真实 SDK / 更新平台接入依赖
外部材料，应尽早确认，不能留到候选发布前才暴露。

## 4. 验收场景

### 消息与任务切换

1. 未完成旧 plan 后发送新消息，新 activity 不归入旧 plan。
2. 工作完成时长包含用户发送后到首个 activity 的等待时间。
3. 快速 A → B → A 切换时，B 的历史响应和 push 不进入 A。
4. 连续打开 20 个长任务后内存回落，重新进入可从权威历史恢复。
5. 自动化任务离开后不保留长期大窗口，普通任务仍有最新 80 行恢复能力。

### Pi、模型与输入

1. 两个任务拥有不同 Pi Skill 时，清单不串用。
2. 新任务预览不继承最近任务 `sessionId`。
3. 远端 Pi 默认模型正确选中，用户手动切换后不被目录刷新覆盖。
4. `/skill:git` 在界面显示 `/git`，实际发送仍是 `/skill:git`。
5. 阅读历史时主动发送，界面回到底部并持续显示流式回复。

### 附件、分享与系统能力

1. 纯图片、纯文件创建任务时立即显示标题，失败 / 取消后正确回收。
2. 分享短会话、长会话、含失败图片和折叠内容的会话，导出结果符合当前可见语义。
3. 分享取消、页面退出和 App 退后台后无临时资源泄漏。
4. 受限选图只使用用户选择内容；URI 失效时能重新选择。
5. 安全观测 adapter 换号、登出、缺 SDK 时不串用户、不阻断认证。

### Device Link

1. 首次 1013 后短连接成功，再次 1013 继续原拥塞期。
2. 连续稳定 15 分钟后才清除拥塞 streak。
3. 普通网络断开保持 10 秒稳定窗语义。
4. 前后台、撤权和重连后消息补齐且不重复发送本地输入。

### UI

1. 队列操作触控区至少 44vp，点击按钮才执行动作。
2. 模型信息在窄屏、展开横屏、系统字体放大下不溢出。
3. 新增 UI 在 Light / Dark 使用成对语义 token。
4. 弹层保持按钮锚定、只覆盖会话详情栏；Composer 维持现有官方悬浮样式。
5. 120Hz 设备动效连续，减弱动态效果下无依赖动画才能理解的状态。

## 5. 验证与发布门禁

### 每个阶段

- 为新增纯函数、状态机、代次和边界条件补 `entry/src/test/LocalUnit.test.ets`。
- 修改 ArkTS 后执行 DevEco 语法检查或对应 Local Test。
- 执行 `git diff --check -- apps/harmony` 并审阅本阶段完整 diff。
- 用户可见行为至少完成一次真实页面操作；无法操作时明确记录未验证原因。

### 候选发布

按 `apps/harmony/项目鸿蒙端开发指南.md` 顺序执行，不并行启动 Hvigor 任务：

1. 使用 DevEco CLI 确认工程和设备环境，并完成文档 / API 核验。
2. 运行 Harmony Local Test。
3. 在 `apps/harmony` 执行 `devecocli build`，确认生成现有签名配置对应的
   `entry/build/default/outputs/default/entry-default-signed.hap`。
4. 对明确设备执行 signed HAP 覆盖安装；不得安装 unsigned HAP，不得卸载、清数据或重置设备。
5. 签名材料不可用、signed HAP 不存在或覆盖安装提示签名不一致时立即停止，交由用户在
   DevEco Studio 处理。
6. 完成窄屏、展开横屏、Light、Dark、断线重连、长会话和分享矩阵。

## 6. 风险与发布阻塞

| 风险 | 影响 | 控制方式 |
|---|---|---|
| 消息预算误删本地工作 | 草稿、交互或上传不可恢复 | 工作租约先于 LRU；增加淘汰边界测试 |
| 旧 push 越权回写 | 切换任务后显示错误内容 | device + session + generation 三重 fence |
| 自动化任务识别错误 | 缓存策略作用到普通任务 | 只用权威分类字段，不猜标题 |
| 1013 计时器跨连接泄漏 | 冷却异常或重连风暴 | 连接代次和显式销毁测试 |
| 长分享图 OOM | App 卡顿或崩溃 | 像素 / 字节上限、分段或多图、可取消 |
| 观测 SDK 缺失或区域不允许 | 身份归因无法交付 | adapter 安全降级；真实接入列为外部发布阻塞 |
| Harmony 更新服务无契约 | 无法复刻 OTA | 交付渠道身份与兼容评估，不私造协议 |
| 版本号漂移 | 设置页与 Device Link 身份错误 | 三处版本值作为候选发布硬门禁 |
| 本机签名配置被覆盖 | 无法构建 / 安装 | 不修改签名块，只验证 signed HAP |
