## 暂不迁移

- 通知栏直接回答／确认（`ce3e341ea3`）的当前产品裁决是 iOS 专项；Android 本轮不加按钮，Harmony 不应机械移植。若以后决定让鸿蒙通知可操作，需另定跨设备抢答、权限、到期和退场规则。
- Android 更新弹窗宽度、键盘遮挡、手持模式触发与 Start 发送，以及 iOS Live Activity／灵动岛、原生浮窗，属于各平台实现；只在鸿蒙存在同类入口与复现时做等价修复。
- 伙伴群聊、MCP App 卡、Agent Net 附件直传与远程画面属于尚未在 Harmony 交付的完整能力，需要单独规划，不从此次局部修复倒推小组件移植。
