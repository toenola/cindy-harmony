范围依据：[Mobile差异评估](./Mobile差异评估.md)，2026-11-09 用户确认 C1–C4、小项，并追加 D1、D2。
所有用户可见行为以 Mobile / 共享实现为准，先读评估中列出的源码再写 ArkTS。

| 阶段 | 内容 | 依赖 | 说明 |

## 2. 完成定义

### C1
- 容器 append、字符串 props、内联 children（含嵌套与声明 id）、结束行重试、媒体协议大小写，与上游 `RichAnswerStream` 同输入同输出。
- 同一轮富组件已显示的图片不在工具结果里重复出现。

### C2
- 分组键、别名匹配、概览项目数统一用 `projectDir ?? workingDir`；Windows worktree 容器名大小写不敏感。

### C3
- 最后一条用户消息有编辑入口；运行中入口在「…」菜单，发送时才中断。
- 回退带 `requireLatestUser`，失败与 `SESSION_RUNNING` 处理、草稿恢复、离开任务后的落点与 Mobile 一致。
- 与排队消息编辑互斥；附件上传中、排队区非空时不可进入。

### C4
- 解析 `id`、`isBlocking`、`answerConstraints`；开始作答发送一次 `inProgress`；提交前按约束提示；答案键 `id || question`。
- 权限卡支持 `mcp` 分类与 `write_stdin`、`mcp_url` 标题。

### D1
- Markdown ```` ```mermaid ```` 与富组件 `diagram` 都渲染为图；时序图、流程图实测可见。
- 首屏不出现空白条；渲染失败或超时停留源码；深浅色切换后重新渲染。
- 点击进入全屏查看器，可双指缩放。列表滚动流畅，Web 组件不随消息数量增长常驻。

### D2
- 选择器在被控电脑供应商之后，按电脑列出其他在线电脑开放远程调用的供应商；当前 Agent 所在电脑离线时仍显示并标明。
- Agent 在其他电脑上的任务可切换模型、Agent、档位、速度，也可改回被控电脑；pending intent 显示与回流沿用现有逻辑。
- 新建任务可选其他电脑的模型并成功创建；记住的远程选择不可用时退回本机。
- 旧版电脑端不支持时给出明确提示，不卡住。

## 3. 验收门禁

- `apps/harmony` 内 Local Test 全部通过，新增用例遵守 `engineering-conventions.md` §3.2。
- `assembleHap` 通过，按开发指南生成并 `install -r` 安装 signed HAP。
- 真机验证 C3、C4、D1、D2，以及评估第 5 节的验证项；Light / Dark 两种模式都实现，未目检的模式如实记录。
