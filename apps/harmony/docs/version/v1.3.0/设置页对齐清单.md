# Harmony v1.3.0 设置页对齐清单

对照源码：`apps/mobile/app/settings.tsx`、`apps/mobile/src/settings/mobileSettings.ts`、
`apps/mobile/src/settings/updateInfo.ts`。

原则：能复用 Mobile 语义的功能直接对齐；Harmony 没有对应运行时能力时做等价展示，
明确标注“不适用”，不放置点击后无法完成动作的假入口。

## 功能清单

| Mobile 设置项 | Harmony 处理 | 状态 |
|---|---|---|
| 账号头部、身份、邮箱、Relay 状态 | 展示账号名称、邮箱、首字母头像和 Relay 状态/说明；当前不投影 Mobile 头像 URL | 鸿蒙等价 |
| 当前版本、整包版本 | 使用 `AppConfig.appVersion`，与 `AppScope/app.json5` 同步为 1.3.0 | 已完成 |
| OTA 版本、手动检查更新、配套桌面版本 | Harmony 只支持应用安装包更新；页面展示“随整包”，不伪造 OTA 检查按钮 | 鸿蒙等价 |
| Beta 渠道和 Beta 标记 | 当前 Harmony 构建没有 Mobile Beta 渠道，展示不支持原因 | 能力不适用 |
| 任务完成通知 | 使用现有 Harmony Huawei Push Kit / Push Token 流程，放入“通知”分组并对齐行样式 | 已完成 |
| 语音词典 | 从桌面只读拉取快照、缓存、跨电脑选择最新快照、刷新和离线提示 | 已完成 |
| 语言选择 | 保留 Mobile 的设置入口和底部选择样式；当前资源只有简体中文，跟随系统会明确提示暂不支持 | 能力受限 |
| 关于这台手机：设备名称 | PATCH 设备名称、持久化、同步 hello 和桌面设备列表，支持恢复默认名称 | 已完成 |
| 关于这台手机：平台、被控权限 | 展示 HarmonyOS 及“电脑端管理”，不在手机端伪造桌面管理操作 | 已完成 |
| 调试 / 开发者：用户 ID、设备 ID、Auth Server、登录区域 | 默认折叠；长值可点击复制，补充 Device Link 状态 | 已完成 |
| 调试：开发环境、Beta 开关、OTA 运行信息 | Harmony 当前没有 Mobile 的 Dev Server、Beta Store 和 Expo Updates 状态 | 能力不适用 |
| 使用统计开关 / 重置 | Harmony 未接入统计 SDK，显示关闭且不采集，不伪造可切换开关 | 能力不适用 |
| 隐私政策、用户协议、备案号 | 按 CN / Global 端点选择法律链接；CN 展示 App 备案号 | 已完成 |
| 注销账号 | 查询可用性、发送验证码、6 位验证码确认、风险确认、30 天等待期说明；确认后保留 receipt 并在登录页恢复状态 | 已完成 |
| 退出登录 | 清除本机登录态和远程镜像，不影响电脑端任务 | 已完成 |

## 样式对齐

- [x] 分组标题置于卡片外侧 gutter，组内使用一块统一卡片。
- [x] 行最小高度、左右内边距、inset 分隔线和圆角节奏对齐 Mobile。
- [x] 颜色全部使用 Harmony 语义资源，同时覆盖 `base` 与 `dark` 资源集。
- [x] 可收起的“调试 / 开发者”默认收起。
- [x] 语音词典、设备名称、账号注销使用独立页面，并保留返回路径。

## 明确不改动

`TaskCompletionPushService.ets` 及其 Huawei Push Token 获取、刷新、持久化、删除和开关
逻辑未改动；本版只修改 `SettingsPage.ets` 的分组、行内容和样式。
