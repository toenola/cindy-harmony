# Harmony v1.3.8 Mobile 差异评估

比较原版 Cindy `b975dc39bc..0b9a988862`（2026-11-15 至 2026-11-20），以合入后的源码为准。此次 `feat/v1.3.8` 使用原版 `upstream/main` 快照。上游该区间未修改 `apps/harmony`。Mobile 有 265 个非合并提交触及 633 个净变化文件，包含实现、测试和翻译。

## 本版重点

- **沟通。** 底部为「项目 / 沟通 / 自动化」。沟通页同一列表先显示所选电脑范围内的伙伴，再显示原有对话。伙伴行显示名称、来源电脑、消息预览和未读状态。点击可打开伙伴主对话。鸿蒙收件箱入口、筛选和稍后处理已移除。
- **协同详情。** 从当前 Lead 任务查看该团队的 Worker 列表，显示总数、运行中数量、每个 Worker 的名称、模型和状态。点任一行打开对应 Worker 的独立任务详情，展示其历史消息、实时输出与工作过程，并提供返回 Lead 的入口。跨电脑 Worker 使用宿主返回的目标电脑和任务标识。列表区分加载中、没有 Worker 和读取失败。
- **合盖。** Lead 标题下标明协同角色，输入框上方的协同概况条打开底部 Worker 列表。点选后关闭列表并进入单列 Worker 详情。Worker 标题下显示角色，输入框上方提供「返回 Lead」。参考 Mobile 的 [Worker 列表](../../../../mobile/src/session/ContextSheetCollabView.tsx) 和 [任务导航](../../../../mobile/src/session/useSessionOrcaCollab.ts)。
- **展开。** 可用宽度足够时，参考桌面在 Lead 旁显示协同栏，点选 Worker 后并排阅读。空间充足时可同时保留任务列表，空间受限时优先给 Lead 和 Worker 留宽。展开和合盖自动重排，保留当前 Worker、各自的草稿和阅读位置。Lead 与 Worker 之间的分隔线可拖动，协同栏可以收起和恢复。
- **首条验收路径。** 打开电脑端已开启协同且有多个 Worker 的任务，逐个进入正确的详情并返回 Lead。保持某个 Worker 打开，验证展开与合盖往返后仍定位到同一个 Worker。协同展示沿用电脑端已开启的团队。另从沟通页点击伙伴，验证主对话归属和未读状态，再核对下方原有对话。

## 其他候选回归

1. **弱网下创建任务和恢复待发消息。** Mobile 把 `maker:create-session` 的等待预算提高到 120 秒，兼顾慢启动；前台发现队首还在等电脑时，主动复核设备状态并确认握手，保留原发件箱记录。Harmony 的 `NewSessionCreationStore.ets` 已有同 ID 重试和回查，但创建仍走 `DlClient.ets` 默认 30 秒。优先对齐这一个通道的预算，并验证前后台切换错过 presence 时 `InputQueueStore.ets` 能否续发。模拟电脑 40–90 秒才返回、中继换网和撤销远控，观察是否只建一个任务、只交付一条首消息。Mobile 还区分手机自己断线与电脑离线，适合作为同组验收条件。上游 `26e8348cc0`、`b7ff5ad2bf`、`7591b998b9`、`1361bfb3d5`。
2. **已有任务按实际执行电脑校验模型。** Mobile 的 `sessionModelAtSend.ts` 优先检查待切换路由，其次是当前运行路由，按执行电脑和供应商读取目录，阻止已隐藏的精确来源并保留草稿。Harmony 已有发送前可见性守卫，`TaskPage.ets` 也能读其他电脑的目录。需要查清两份目录在发送守卫上的作用域，重点覆盖控制电脑与执行电脑拥有同名模型、其中一个来源被隐藏或暂停、切换后目录尚未回来的场景。上游 `53d139436c`、`d6653bc48a`、`7822ba9217`。
3. **任务页键盘和长权限卡。** Mobile 在发送成功且用户没有继续输入时收起键盘，失败保留草稿；长权限说明单独滚动，任务标题和按钮持续可见，布局以当前展示的队列条目为准。Harmony 在 `NewSessionPage.ets` 已能清除焦点，先核验普通任务发送分支；`TaskPage.ets` 的 `permissionCard()` 将说明和操作放在同一列，重点验收小窗口、大字体、键盘弹起和多条请求切换。上游 `93beb3df26`、`ea71ea5ffe`、`49c2d74f64`、`89d29f344d`。
4. **文件预览与列表刷新做定向回归。** Mobile 统一 Windows 盘符路径的宿主读取，修正文件 URL 的宿主解析、HTML MIME 与缺失资源反馈，以及项目排序显式刷新和并发读取。Harmony 已有宿主文件读取和 SVG 预览，也有远端项目顺序存储。先用 Windows 电脑走消息附件和输入区预览，再测同一电脑的项目顺序改动、手动刷新及跨设备项目归属；按复现结果修补。可同轮验证短暂离开任务再返回时，历史分页和阅读位置能否恢复。上游 `3f0275e964`、`0fcba5e14a`、`833bd35e5b`、`ea124a285a`、`257a6d84fc`、`0af244f3aa`。

## 独立排期

- **项目管理。** 项目图标、目录授权和从仓库链接新建项目适合单独交付。参见[项目设置产品规则](../../../../../docs/product-rules/project-settings.md)。
- **基于已有入口继续评估。** Mobile 侧边栏新增套餐余量与 Token 用量，以及任务生成速度读数，Harmony 已在模型选择器展示账号额度。表格正文连续选择、整表复制和消息尺寸稳定，随鸿蒙原生表格体验评估。Orca 子任务提问跳转、自动化失败原因、PR 跟进模型和状态反馈，先核对鸿蒙现有入口和宿主投影。
- **平台专项与新链路。** iOS 灵动岛、系统分享和小组件，以及 Android 原生手势、折叠屏远程键盘和 ABI 修正，按鸿蒙场景取舍。Agent Net、插件 Harness、代输入、关注同事共享任务、伙伴群聊和礼品卡涉及新入口或授权，适合独立排期。远程 worktree 的 300 秒等待仅适用于 `worktree:create`，当前鸿蒙新建任务没有这个独立调用。

## 验证

单测覆盖伙伴主对话链接、未读所需的时间字段、跨电脑 Worker 路由及分隔线限宽。真机验收关注伙伴主对话和原有对话的切换，以及折叠屏重排、拖动分隔线和收起协同栏。
