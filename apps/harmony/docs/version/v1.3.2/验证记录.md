## 内部核对已修问题

1. 仅切换电脑且 Agent／模型相同的 pending intent 曾会提前清空。现在位置、来源、effort、
   fast mode 等目标字段均按声明比较，不再因同名模型解除远程保护。
2. 关闭模型重选原先仅接入新建页。已有任务在消费草稿与附件前核对当前／pending 目标，
   提示重选并保留输入；远程任务不拿被控电脑目录作错误判定，既有 learn 本地入口保留。
3. 控制目标设备清单不包含手机与自身，不能据此判断来源手机已删除。来源名字现在使用
   独立全平台目录，完整快照未加载前不作删除判断，账号变化清理旧目录。
4. 新增协同卡片与分享选择的边界按 Mobile 排除 orcaCard，来源标签不进入分享投影。
5. 删除 RPC 增加排队前与回包后读取 lease 复验，二次确认也复验账号、设备、任务与消息身份。
6. 5a 首轮出现 1 项失败：空 Host 投影会把本地未发送输入放入过渡层，原重试查不到它。
   现在仅凭本地未发送证明恢复初次发送；CHANNEL_NOT_ALLOWED 或 unknown 从不充当证明。
   保留原断言后最终 429 项全部通过。
