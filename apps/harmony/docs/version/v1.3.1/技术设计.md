# Harmony v1.3.1 技术设计

> 2026-09-10；范围仅 `apps/harmony`。行为依据以当前合并的 Mobile / shared 源码为准。

## 历史视图与恢复

`HistoryViewAdapter` 读取 LINK_ACCEPT 的 `history-view-v1` 能力，复用
`local-db:messages:view`、`work-details`、`view-intent`。请求前完成 peer link 建立；
只对能力未声明或明确返回通道不支持的 Host 使用旧 `messages:list`。超时、断网、
无效数据均作为读取失败，不能证明 Host 不支持能力。

历史页保留用户/助手正文及工作摘要，工作正文只在展开后自动连续读到该范围结束。
读取意图按任务串行发送完整展开集合；收起和离开时释放意图。摘要引用带 revision；
旧详情请求不能覆盖新 revision、另一个设备、另一页面 lease 或新的连接。临时摘要
只存在于内存渲染窗口，以 `history-work:` 区分；写入原始消息快照前过滤，不发送给 Agent，
不修改 Host transcript。零耗时工作摘要也保留展开入口。

重新读取最新视图时，仅在最新页首个来源与旧窗口存在精确边界时保留旧前缀。
没有可靠边界时重置分页游标，不把断开的历史片段伪装成连续历史。展开详情按摘要版本
保留，分页游标由 Host 管理，不用可见行数推算。旧 Host 保留已有帧超限降页和 gap healing。

`SnapshotReadPool` 的历史读取身份包含设备、任务、连接代次、页面 lease、恢复代次、
窗口参数和推送权威版本。相同身份复用在途读取；失败后清理，不缓存失败 Promise。
读取期间新到的权威推送逐行优先，删除/换分支使旧响应失效。流式块完成仅结束运行标记，
对应正式消息尚未接管时仍保留正文；旧 persistId 的消息不能清掉新块。

历史、输入投影、待确认项分别发布与重试。`RemoteReadRetries` 为单项提供 2/4/8 秒的
有限退避；成功、页面/账号清理后取消，离线不发起请求，重连重新读取。翻旧页失败保留
原位置和重试入口，不重放已成功的队列/确认项请求。

### 故障半径三问

1. **触发条件**：本次新增恢复处理的是单个只读请求失败；peer/relay 断连仍交给现有
   DlClient 连接状态机。无能力与网络错误分开判断，聚合背压不触发立即全量重放。
2. **恢复动作**：仅重读失败的资源；不关闭 peer、不停止共享 WebSocket、不登出，
   不扩大到其他设备或控制端。连接代次只使本端旧读取失效。
3. **多控制端证据**：本地测试验证一个读取挂起/失败时另一读取可独立完成、旧代次不能
   写回，以及跨设备预览/消息隔离。真实“两个控制端共用 Host，一个静默而另一个继续”
   拓扑尚未联调，见验证记录，不能用本地测试替代该结论。

## 模型来源

`ComposerCatalog` 同时服务新建与已有任务。目录行保留 providerId，不按模型 ID 合并
不同账号。展示 Host 的公开账号标识；同名分组用 providerId 消歧。隐式来源在提供当前
模型的连接中优先选择 Codex 的 OpenAI、其次 XD，其他 Agent 优先 XD；显式失效来源
不自动高亮其他账号。实际任务可保留停用/退役的当前行，新路由不能选它。

有效空目录是权威结果，不能用扁平列表绕过隐藏或权限配置。仅明确不支持 provider:list
时允许旧 capabilities 回退；加载失败保留同设备已有选择，新建发送前目录未就绪则重读，
不把暂时缺失当默认模型。旧 Host 没有可见性字段时沿用目录本身。

目标窗口和当前用量均有效时，本地用量达到目标窗口要求确认；SSH 达到 90% 阻止切换。
未知或非有限数值放行，与 Mobile 一致。确认回调校验当前页面和任务，取消不修改选择。

## 工作目录偏好与电脑标注

`NewSessionPreferenceStore` 使用独立的 `cindy_new_session_preferences` 应用沙箱偏好文件，
不复用凭证文件，退出登录不会删除所有账号的目录偏好。按账号保存工作区类型，按设备
保存显式选择的目录；目录原样保存，不 trim 成另一个路径。写入串行并捕获账号，恢复
校验账号代次与编辑版本，慢磁盘读取不能覆盖新选择。内存账号切换立即清空旧投影。

项目机器名只在全设备视图展示。同名判断仅覆盖当前可见项目涉及的不同设备；同名时
补设备 ID，离线状态进入渲染 key。单设备标题已提供机器身份时不重复标注。

## 附件、草稿与用量

`LocalAttachmentPreviews` 只持有最多 128 条内存 URI 引用，按设备隔离，不接管文件删除。
新建/已有任务发送时登记；任务页在远端图片解码完成前保留本地底图，完成后释放。
账号清理移除全部预览引用；新建失败的原附件恢复流程继续复用。没有扩建磁盘媒体缓存。

输入区收起前保存并 flush 当前文档；队列草稿保护、中文输入原生 onChange、上翻锚点和
32ms 文本增量合并沿用现有实现，通过既有自动化用例回归。实机键盘/图片/滚动观感未验证。

菜单只读取既有 usage 通道，按实际 provider/model 决定 OpenAI 账号或网关来源；自定义
账号响应必须证明 providerId 一致，否则显示不可用。泛用和当前模型额度同时展示，过期
窗口隐藏；币种只接受 Host 明确的 CNY/USD，缺失不显示为零。配额、上下文 tokens 与
任务消耗分别呈现，菜单打开时每分钟刷新，离开后停止。未开放远程用量通道的供应商
及 SSH 显示不可用，不猜测账户余额。

新增 UI 使用语义颜色；文案资源覆盖简中、繁中、英文、日文、韩文。所有产品操作仍使用
ArkUI 原生界面，不移植 RN/WebView 补丁。

## 变更历史

### 2026-09-10 — 四项 Mobile 对齐

**变更内容**：新增历史视图适配、读取合并/重试、供应商路由保护、工作区偏好、电脑标注、
预览交接与账户用量菜单。

**变更理由**：上游历史读取和多账号语义已更新，鸿蒙需补齐来源与生命周期边界。

**影响范围**：Harmony 的 Device Link 消费、消息窗口、模型选择、新建任务及菜单；
无服务端、Desktop、Mobile、共享 package 修改；应用版本更新到 1.3.1。

**已知限制**：API 26 实机、双主题与弱网多控制端联调待完成。签名配置保持用户原有值；
不通过卸载/清数据绕过签名或设备环境限制。
