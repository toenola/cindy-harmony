# Harmony v1.3.1

> 状态：候选发布（待 API 26 设备验收）
>
> 开发分支：`feat/v1.3.1`
>
> 上游基线：`abcf92c2b`；合并提交：`054464f64`

本期范围于 2026-09-10 确认，包含四项：

1. 历史按需加载、流式正文交接、弱网恢复与重复请求合并。
2. 多账号供应商来源显示、停用来源处理、小上下文模型切换保护。
3. 新建任务目录记忆与同名电脑、项目标注。
4. 附件发送连续性、长历史滚动、草稿恢复、配额与用量展示。

开发与验证仅限 `apps/harmony`，目标为 HarmonyOS 7.0 / API 26+。四项功能实现和本地自动化已完成；版本已更新为 1.3.1。签名包可构建，实机交互与真实弱网联调待验收。
